# Analog Devices (Maxim) MAX30102 pulse oximeter and heart-rate sensor module (synthetic test datasheet)
SYNTHETIC SUMMARY FOR SOFTWARE TESTS - NOT MANUFACTURER DOCUMENTATION.

## Features
Integrated module with red and infrared LEDs, photodetector, optical elements and low-noise
electronics with ambient light rejection. I2C interface. Separate supplies for logic (1.8 V)
and LEDs (3.3 V). 14-pin optical module package. Applications: wearable SpO2 and heart rate.
