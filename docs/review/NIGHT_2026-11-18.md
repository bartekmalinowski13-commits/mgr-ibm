  current fixtures never trigger it, so CI was green.

  turns enforcement off while the old IdP stays live. Both touch `auth.py`/`sso.py` (owner).
- **Ops:** LLM gateway image listens on IPv6 only since #81 (AWS VPC is IPv4); `tools/deploy.sh`
  rolls out images before migrations; the restore drill cannot verify a real dump.

  cap and ODB++ ZIP size limit can be bypassed; KB documents are parsed without a sandbox.
- **API/Web:** non-problem+json 500s, malformed audit cursor gives 500, KB uploads skip the
  storage quota, a new idempotency key per submit can create duplicate billable runs.
