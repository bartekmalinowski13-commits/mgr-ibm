# M1 – Domain core (plan)

Sources: ROADMAP M1, FORMATS.md, ARCHITEKTURA_WARIANTOW.md, STRUKTURA_PRACY.md (metrics).

## Brainstorming – questions and answers
| Question | Decision | Rationale |
|---|---|---|
| Where does `ParsedDesign` live? | `bom-core` | a shared input contract of the A/B runtimes (ADR-0007); parsers only produce it |
| Provenance at the item level or the field level? | per field (`provenance: {field: Provenance}`) | the "provenance panel" UI and the audit must know who determined the MPN and who the quantity |
| Own S-expr parser or a library? | own, iterative, with limits | untrusted files (SECURITY.md); zero dependencies in the sandbox worker |
| Where do the KiCad fixtures come from? | own, generated by a script, CC0 | no licensing risk; open-source projects up to M8 are chosen by a human |
| How to compute MPN accuracy, given that a 10k 0603 resistor has many correct MPNs? | the reference BOM has an `MPN Alternates` column | a fair evaluation of the variants |
| How to define an MPN hallucination? | an MPN absent from every trusted source (reference, alternates, design, KB catalog) | measurable without network access; the KB catalog arrives in M2 |
| IEC 60601 – a verdict or a flag? | a `review` flag for a human | the tool supports, but does not replace, the risk file (SECURITY.md – regulatory item) |
